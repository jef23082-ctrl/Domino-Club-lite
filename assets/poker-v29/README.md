# Cartes Poker V29 — ivoire, émeraude et or

Création avec l’outil de génération d’images intégré (pas de service externe ni d’API payante séparée).
Référence de style : photo fournie par l’utilisateur, dame de carreau et dos ornementé.
Les originaux générés sont conservés ; les cinq PNG de ce dossier sont les actifs utilisés par le jeu.
Les trois illustrations sont communes aux quatre couleurs, dont les indices sont ajoutés par le code.
Le même cadre HTML/CSS détermine les dimensions de toutes les cartes, indépendamment des images.
